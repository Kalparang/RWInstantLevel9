# RWInstantLevel9

Ravenswatch에서 판 종료 후 **영구 영웅 경험치를 받으면 해당 영웅을 즉시 9레벨로 올리는** 비공식 모드입니다.

- 영구 레벨 9 미만이고 획득 경험치가 양수일 때만 적용됩니다.
- 경험치가 0이거나 이미 9레벨이면 기존 처리를 유지합니다.
- 한 판 안에서 사용하는 전투 레벨은 변경하지 않습니다.

## 지원 버전

- Windows x64
- Ravenswatch `1.06.00.04` / Steam build `25174305`
- 지원 `Ravenswatch.exe` SHA-256:
  `B9C3642884A8F3A463782F36C9A3A62BC14C88105315220C733FE6C2229BA904`

게임 실행 파일의 해시와 후킹 지점이 일치할 때만 활성화됩니다. 게임 업데이트로 실행 파일이 바뀌면 모드가 비활성화됩니다. 다른 버전은 지원하지 않습니다.

## 설치

1. 게임을 정상 종료합니다.
2. Steam에서 게임의 **설치된 파일 → 찾아보기**로 설치 폴더를 엽니다.
3. 설치 폴더의 **`_Save` 전체를 다른 위치에 백업**합니다. 이 배포본에는 자동 백업 기능이 없습니다.
4. 배포본의 `winhttp.dll`을 `Ravenswatch.exe`와 같은 폴더에 복사합니다.
5. 게임을 실행하고 원하는 영웅으로 플레이하여 판 종료 후 영구 경험치를 받습니다.

설치 폴더에 `winhttp.dll`이 이미 있으면 덮어쓰지 마세요. 같은 DLL 이름을 사용하는 다른 모드와 함께 설치할 수 없습니다.

## 비활성화 및 제거

- 일시 비활성화: 게임 종료 후 설치 폴더에 `RWInstantLevel9.disabled`라는 빈 파일을 만듭니다. 이 파일을 지우면 다음 실행부터 다시 활성화됩니다.
- 제거: 게임 종료 후 이 모드로 설치한 `winhttp.dll`을 삭제합니다.
- 이미 획득한 영구 레벨은 모드를 제거해도 유지됩니다. 이전 진행도로 되돌리려면 세이브 백업이 필요합니다.

## 동작 확인 및 제한

게임 폴더의 `RWInstantLevel9.log`에서 `READY`는 로딩 완료, `COMMIT ... reached9=yes`는 게임이 9레벨 성장도를 반영했다는 뜻입니다. `REFUSED`는 버전 또는 후킹 지점 불일치 등으로 적용을 거부했다는 뜻입니다.

실제 단독 플레이에서 9레벨 반영과 정상 세이브 저장을 확인했습니다. 재실행 후 유지, 보상 해금 전체, 협동 플레이는 별도 검증 전입니다. 결과 화면 일부 경험치 요약에는 보정 전 획득량이 표시될 수 있습니다.

## 배포 파일

- `winhttp.dll`: 모드
- `SHA256SUMS.txt`: DLL·소스·문서·라이선스의 SHA-256 체크섬
- `THIRD_PARTY_NOTICES.txt`: 포함된 MinHook 및 HDE 라이선스
